# QA run — Wyszukiwarka i filtry instytucji — 2026-08-14

## Brief
- **URL:** https://kwalifikacje.gov.pl/wyszukiwarka-instytucji/?limit=20&offset=0
- **Feature:** Wyszukiwarka kwalifikacji + filtry (Zadania w ZSK, Kategoria kwalifikacji, Siedziba instytucji certyfikującej) + widok profilu instytucji
- **User story:** Jako user chcę wyszukać instytucję, kliknąć w wyszukany kafelek i zapoznać się z informacjami. Ponowić szukanie dodając filtrów.
- **Priorytet:** P1
- **Anti-scope:** wersja mobilna, performance/load, integracje z zewnętrznymi rejestrami (ZRK API tylko as-is).
- **A11y note:** WCAG 2.2 AA częściowo pokryte (INST-10/11 — structure/naming). Kontrast, real screen-reader flow, keyboard focus-visible poza zakresem automatycznego testowania.

## Coverage summary

- **Positive core (5)**: search po nazwie (INST-01), 3 filtry (INST-02/03/04), klik → profil (INST-05)
- **Combined flow (1)**: search + 2 filtry razem AND-logic (INST-06)
- **Negative (1)**: search bez dopasowań, empty state (INST-07)
- **Bundled edges (2)**: polskie znaki+cudzysłowy+case w 1 query (INST-08), XSS URL injection (INST-09)
- **A11y (2)**: accessible names (INST-10 FAIL — 2 SVG buttons bez aria-label), semantic structure + aria-live (INST-11 PASS)

Wszystkie 3 filtry przetestowane: `roles=` (Zadania w ZSK), `qualification_categories=` (Kategoria), `cities=` (Siedziba). Klik-in-profile działa poprawnie — profil zawiera NIP/KRS + adres siedziby.
