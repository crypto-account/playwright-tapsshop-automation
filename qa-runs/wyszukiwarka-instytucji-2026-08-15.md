# QA run — Wyszukiwarka instytucji (kwalifikacje.gov.pl) — 2026-08-15

## Brief
- **URL:** https://kwalifikacje.gov.pl/wyszukiwarka-instytucji/?limit=20&offset=0
- **Feature:** wyszukiwarka-instytucji
- **User stories:**
  - S1: Jako end user chcę wyszukać instytucję, sprawdzić listę, kliknąć w kafelek i zobaczyć czy się otwiera w nowej karcie, czy jest zgodny z prawdą i czy link tam działa.
  - S2: Jako end user chcę zweryfikować działanie filtrów „zadania ZSK", „kategoria kwalifikacji", „siedziba instytucji certyfikującej" oraz kliknięcie w ikonę pomocy (?), i zweryfikować że modale się otwierają i wyświetlają treść.
  - S3: Jako end user chcę pobrać zawężoną listę klikając „Pobierz".
  - S4: Jako end user chcę sprawdzić paginację strony klikając Następna/Poprzednia.
- **Priorytet:** P1
- **Anti-scope:** pomijamy testowanie API bezpośrednio (tylko UI), tłumaczenia / wersje językowe (EN), integracje z zewnętrznymi rejestrami, header / footer / menu główne (tylko widget wyszukiwarki).
